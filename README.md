# 교통체증 시뮬레이터

서쪽→동쪽 한 방향 도로에서 차가 움직이며 줄이 생기는 과정을 보는 프로젝트입니다. 기본은 1차선이고, 4차선까지 늘릴 수 있습니다. 교통량을 숫자로만 계산하지 않고, 차선 위의 위치와 속도가 매 순간 갱신됩니다.

차는 서쪽 끝에서 들어와 앞차와 거리를 유지한 채 동쪽으로 나갑니다. 화면의 급브레이크와 끼어들기 버튼은 도로 위의 차 하나를 골라 그 행동을 시킵니다. 급브레이크는 뒤차까지 속도를 늦추고, 끼어들기는 2차선 이상에서 옆 차선으로 들어갑니다. 분당 횟수를 올리면 같은 행동이 자동으로 반복되고, 0이면 버튼으로만 일어납니다.

정체는 화면에서 봅니다. 버튼을 눌러도 차 설명창은 열리지 않고, 차를 직접 클릭할 때만 열립니다.

시뮬레이션 엔진은 React와 분리되어 있습니다. 화면은 엔진이 만든 상태만 읽어서 3D로 그립니다.

```text
Simulation Engine
        ↓
Simulation State
        ↓
3D Renderer
        ↓
UI
```

같은 시드로 다시 돌리면 같은 차가 같은 시각에 들어옵니다. 차선 수처럼 도로가 바뀌는 설정은 다시 시작해야 적용되고, 분당 횟수는 바로 적용됩니다.
