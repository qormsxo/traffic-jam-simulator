# 교통체증 시뮬레이터

십자 교차로에서 차량이 실제로 움직이며 정체가 생기는 과정을 보는 프로젝트입니다. 교통량을 숫자로만 계산하지 않고, 차선 위의 위치와 속도가 매 순간 갱신됩니다.

차량은 진입로에서 생성되어 앞차와 거리를 유지하고, 신호에 따라 멈추거나 통과한 뒤 직진·좌회전·우회전으로 빠져나갑니다. 앞차가 느려지면 뒤차도 감속해서 줄이 길어집니다.

시뮬레이션 엔진은 React와 분리되어 있습니다. 화면은 엔진이 만든 상태만 읽어서 3D로 그립니다.

```text
Simulation Engine
        ↓
Simulation State
        ↓
3D Renderer
        ↓
UI / Statistics
```

같은 시드로 다시 돌리면 같은 차량이 같은 시각에 들어옵니다. 차선 수나 신호 주기만 바꿔 A/B를 비교할 수 있습니다.

실시간으로 현재 차량 수, 평균 속도, 최대 정체 길이, 평균 통행시간, 평균 대기시간, 완료 차량 수, 시간당 처리량을 보여 줍니다. 차량 수와 평균 속도는 그래프로도 쌓입니다.
