# 카페 키오스크 시뮬레이션

카페에 손님이 들어와 키오스크로 주문하고 음료를 받아 나가는 과정을 돌려 보는 프로젝트입니다. 키오스크 대수, 손님 구성, 시간대를 바꿔 가며 줄이 어떻게 늘고 줄는지 눈으로 확인합니다.

손님은 혼자 오거나 무리로 옵니다. 무리에서는 한 명이 주문하고 나머지는 옆에서 기다립니다. 한 팀은 입장, 키오스크 대기, 조작, 메뉴 고민, 결제, 제조 대기, 픽업, 퇴장을 거칩니다. 화면의 몸 색은 연령이고, 머리 위 점은 지금 어느 단계인지 표시합니다.

연령은 키오스크 앞에서 보내는 시간에 영향을 줍니다. 10대에서 30대는 짧게, 40대부터는 점점 길게 잡는 가정이 들어 있습니다. 실제 사람의 능력을 단정하는 수치가 아니라, 손님 구성이 바뀌면 줄이 어떻게 달라지는지 보기 위한 설정입니다.

평일, 쉬는날과 오전,점심,오후,저녁,마감을 고르면 손님 수, 무리 비율, 연령 분포, 고민 결제 제조 시간이 그 상황에 맞게 바뀝니다. 출근 시간에는 혼자 온 직장인이 많고, 점심에는 무리가 몰리고, 주말 오후에는 가족과 지인이 오래 머무는 식입니다.

같은 조건을 다시 돌리면 같은 결과가 나옵니다. 시뮬레이션이 끝난 뒤에는 평균 대기, 체류 시간, 처리한 손님 수, 시간당 처리량, 연령대별 키오스크 사용 시간을 보여 줍니다.
